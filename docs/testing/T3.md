## Top defects (by severity)

1. **Weight-goods refunds are priced 1000× too high** (`refunds.js:173`). Repro: `POST /api/sales/checkout {branchId:"seed-branch-main", paymentMethod:"CARD", items:[{productId:<WEIGHT product>, quantity:250}]}` → total 10.00. Then `POST /api/refunds {branchId, saleId, items:[{productId, quantity:100}], note:"x"}` → refund `total:"4000"`. That would pay out 4000 QAR and inflate refunds in cash-up and P&L. Without a note the call is blocked only by the high-value-note rule.
2. **Refund restock writes no StockMovement** (`refunds.js:224-297`). This breaks the "Movement only" binding rule. Repro: refund 1 unit with restock → `Inventory.quantity` +1, but `select count(*) from "StockMovement" where reason='RETURN'` stays 0.
3. **Stock comes back by default** (FR-80). The API treats a missing `restock` as true, and the Returns UI checkbox is pre-ticked. Repro: `POST /api/refunds {branchId, saleId, items:[{productId:P, quantity:1}]}` (no restock field) → stock +1.
4. **A refund can exceed what was paid and need not reference a sale.** Repro: sale P×2 with `discountAmount:5, discountReason:"x"` (total 15) → full refund total 20. Separately, `POST /api/refunds` with no `saleId` → 201, priced at list price, restocks.
5. **Cashier's till never shows today's grooming** (FR-29). `/api/appointments` is ADMIN/MANAGER-only and `POS.jsx` hides the 403. Repro: cashier token, GET `/api/appointments?branchId=seed-branch-main&day=<today>` → 403.
6. **Cash-up has no card total** (FR-102/FR-109). Expected cash also ignores refunds of sales from earlier sessions and refunds with no sale.
7. **Cashier cannot refund by default** (403 FORBIDDEN, `permissions.js:51`), against FR-28's wording.
8. **Unknown payment method is silently stored as CASH**. `paymentMethod:"BITCOIN"` → 201, CASH, added to the drawer's expected cash. Also, `/api/sales/payment-link` returns a bare 500 when SkipCash fails.
9. **The till does not ask for a location on open** (FR-30). It uses the active header branch.
10. **Dead offline SALE/REFUND replay queue is still shipped** (NFR-10 latent risk).
